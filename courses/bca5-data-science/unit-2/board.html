Normal distribution · maths

The z-score

z = (x − μ) / σ

How many standard deviations a value is from the mean.

  • z = 0 → exactly average
  • z = +2 → 2 SD above
  • |z| > 3 → very unusual (outlier?)

How often does a delivery take over 45 min?

z = (45 − 31.4) / 6.4 = 2.13
P(Z > 2.13) ≈ 0.017 → about 1.7%
Real data: 12 of 600 = 2.0%. The model works.
Probability · maths

Probability basics

P(A) = favourable / total, 0 ≤ P ≤ 1
P(late) = 52 / 600 = 0.087
Complement: P(not A) = 1 − P(A)
Addition: P(A or B) = P(A) + P(B) − P(A and B)
Independent: P(A and B) = P(A) × P(B)

Conditional: P(A | B) = P(A and B) / P(B)

Central Limit Theorem and standard error

Means of samples (n ≥ 30) are approximately normal, whatever the shape of the data.

Hypothesis testing

Hypothesis testing: a courtroom

H₀ (null): no effect, no difference
“The app does not change delivery time.” μold = μnew
H₁ (alternative): the claim to prove
μold ≠ μnew
α (significance level): risk of a false alarm we accept, usually 0.05
p-value = P(result at least this extreme | H₀ true)
p < α → reject H₀ (significant)
p ≥ α → fail to reject H₀
“not guilty” ≠ “innocent”

Z-test · maths

Z-test: is the machine under-filling?

H₀: μ = 1000 g   H₁: μ ≠ 1000 g
n = 40, x̄ = 995.38 g, σ = 12 g (known), α = 0.05
SE = σ / √n = 12 / √40 = 1.897
z = (x̄ − μ₀) / SE
= (995.38 − 1000) / 1.897 = −2.43
|z| = 2.43 > 1.96 · p = 0.015 < 0.05
Reject H₀: recalibrate the machine.

ANOVA · maths

One-way ANOVA: are the partners equally fast?

Means: SwiftShip 29.8 · QuickDrop 30.4 · ExpressGo 34.3 min

F = variation between groups / variation within groups
MSB = 2230.5 / 2 = 1115.3
MSW = 22363.8 / 597 = 37.46
F = 1115.3 / 37.46 = 29.77
F > 3.01, p < 0.001 → reject H₀. At least one partner differs. By city: F = 1.24, p = 0.29 → no difference.
Python · interpretation

Reading results like a data scientist

from scipy import stats
stats.ttest_ind(old, new, equal_var=False)
# t = 4.84, p = 1.6e-06
stats.f_oneway(swift, quick, express)
# F = 29.77, p = 4.7e-13
stats.chi2_contingency(table)
# chi2 = 40.85, p = 1.3e-09, dof = 2
  • Report the test, the statistic, the p-value and the effect size
  • “Fail to reject” ≠ “proved equal”
  • Significant ≠ important: 0.2 s with p = 0.001 is useless
  • End with a business sentence: “Roll out the app: it saves 2.5 min per order (p < 0.001).”
