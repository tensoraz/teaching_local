Definition

What is data science?

Combining statistics, programming and domain knowledge to extract insight from data and turn it into decisions or data products.

Not “making charts”. Not “just AI”.
The goal: a better decision than without data.

Why cleaning matters: one bad value

Customer ages entered in a form:

21, 22, 23, 24, 250 ← typo for 25
Mean = (21+22+23+24+250) / 5
= 340 / 5 = 68
Median = middle value = 23
Garbage in → garbage out
“Our average customer is 68” leads to the wrong marketing plan.
Duplicates
A ₹20,000 order recorded twice = revenue overstated by ₹20,000.
Inconsistent text
“delhi ” and “Delhi” split one city into two.

DS vs AI vs ML

ML · maths

What does “learning” mean?

Traditional: Rules + Data → Answers
Machine learning: Data + Answers → Rules

Model: ŷ = m·x + c
Learn m, c to minimise Σ(y − ŷ)²
m = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)²
c = ȳ − m·x̄
Delivery days xRating y
15
24
34
x̄ = 2, ȳ = 4.33
m = (−0.67 + 0 − 0.33) / 2 = −0.5
c = 4.33 + 0.5·2 = 5.33
Predict x = 4: ŷ = 3.33 ★

CRISP-DM

CRISP-DM: the industry-standard method

CRoss-Industry Standard Process for Data Mining

  • Created 1996–2000 by an industry group
  • Industry-neutral, tool-neutral
  • Iterative: going back is normal
  • Starts and ends with the business
  • Most widely used process model
CRISP-DM

Six phases, six deliverables

PhaseKey questionDeliverable
1 Business UnderstandingWhat is the goal? How do we measure success?Objectives, success criteria, plan
2 Data UnderstandingWhat data do we have? Quality?Data quality report
3 Data PreparationHow do we make it model-ready?Final clean dataset
4 ModelingWhich technique fits?Models + parameters
5 EvaluationDoes it meet the business goal?Go / no-go decision
6 DeploymentHow is it used and maintained?Live solution, monitoring plan, report

Data-driven decisions · maths

Decision maths: expected value

Buy 200 extra phones for Diwali? Cost ₹9,000 · price ₹11,000 · unsold returned at ₹7,500

Profit if sold = ₹2,000
Loss if unsold = ₹1,500
EV = p × 2000 − (1 − p) × 1500
Break-even: 2000p = 1500(1 − p)
3500p = 1500 → p ≈ 0.43
Last Diwali’s data: 70% of extra stock sold → p = 0.7
EV = 0.7×2000 − 0.3×1500
= 1400 − 450 = ₹950 / phone
× 200 = ₹1,90,000 → BUY
Data-driven decisions · maths

Prove it: the A/B test

VisitorsOrdersRate
A (old page)5,0002004.0%
B (free-delivery banner)5,0002454.9%
Lift = (4.9 − 4.0) / 4.0 = +22.5%
p̂ = 445 / 10000 = 0.0445
SE = √( p̂(1−p̂)(1/nA+1/nB) ) ≈ 0.00412
z = (0.049 − 0.040) / 0.00412 ≈ 2.18
|z| = 2.18 > 1.96 → difference is real (95% confidence). Launch B.
Data-driven decisions

Traps: correlation ≠ causation

🍦 Ice-cream sales ↑ and drowning ↑ together.
Does ice-cream cause drowning? No: summer heat causes both.
r = cov(x, y) / (σx σy),  −1 ≤ r ≤ 1
Lab: delivery days vs rating → r = −0.47
  • Sampling bias: data misses some people
  • Survivorship bias: only studying winners
  • Confirmation bias: seeing what you want
  • Vanity metrics: downloads ≠ orders
  • GIGO: garbage in, garbage out
