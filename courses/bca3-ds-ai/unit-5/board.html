Monitoring · maths

Monitoring: is the model still valid?

PSI = Σ (A − E) × ln(A / E) over bins
bin 1: (0.248 − 0.099) × ln(0.248/0.099)
= 0.149 × 0.918 = 0.137
all 10 bins: PSI = 0.339
PSI< 0.100.10–0.25> 0.25
Meaningstablewatchact
Data drift: inputs change. Mean credit score 690 → 651 this month.
Concept drift: the input→outcome link changes (rates rise, same person now riskier).
Respond: alert → investigate → retrain → champion–challenger or A/B test, or run the new model in shadow mode first.
