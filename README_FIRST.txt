OFFLINE CLASSROOM - CLEAN VERSION

1. Extract this folder.
2. Open it in VS Code.
3. Terminal -> New Terminal.
4. Run: python classroom.py
5. Open the Students address shown in the terminal.
6. Open /teacher on your laptop for teacher control.

LOCAL TEST:
http://127.0.0.1:8000
http://127.0.0.1:8000/teacher

LAB:
Connect laptop by Ethernet to the same LAN as student PCs.
Give students the LAN address printed by classroom.py.

No internet is required.
